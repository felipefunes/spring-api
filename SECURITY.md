# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

- Preferred: use [GitHub's private vulnerability reporting](https://github.com/felipefunes/spring-api/security/advisories/new) for this repository.
- Alternative: email felipefunes@gmail.com with details of the issue.

Please include as much information as possible (steps to reproduce, affected version, potential impact) so the issue can be triaged quickly.

We will acknowledge receipt within a reasonable timeframe and keep you informed as the issue is investigated and resolved.
